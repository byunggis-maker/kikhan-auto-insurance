**3. 엑셀 라이브러리 경고(moderate 2건) — 내보내기 전용이라 그대로 둠**

- 2건은 exceljs 4.4.0과 그 안의 uuid 8.3.2 하나의 같은 경고입니다(GHSA-w5hq-g745-h8pq: uuid v3·v5·v6에 buf를 넘길 때 범위 검사 누락).
- exceljs가 uuid를 쓰는 곳은 `lib/xlsx/xform/sheet/cf-ext/cf-rule-ext-xform.js` 한 곳, `v4()`를 buf 없이 부르는 조건부서식 처리뿐입니다. 경고 대상(v3·v5·v6 + buf)이 아닙니다. 이 앱의 엑셀은 조건부서식도 쓰지 않습니다.
- 사용자가 올린 xlsx를 읽는 경로는 없습니다: 앱의 exceljs 사용은 `lib/export/excel.ts`의 쓰기(`xlsx.writeBuffer`)뿐이고, 서류 올리기는 PDF·JPG·PNG·HEIC만 받으며(화면 accept), 서버가 파일 첫 바이트로 다시 가려 그 밖은 415로 거절합니다(`lib/ai/documents.ts detectKind`).

**4. 법령 API 사전 점검**

- 확인한 것: open.law.go.kr의 OPEN API 신청 화면에 도메인주소와 서버 IP를 등록하고, 공식 공지(IP 접속이력)는 "등록된 사용자에게만 제공" 오류가 나면 OC에 등록된 IP와 요청한 IP를 대조해 보라고 안내합니다. 즉 **IP를 검사합니다.** 거절도 HTTP 200에 "사용자 정보 검증에 실패하였습니다" 같은 글로 온다는 개발자 기록이 있습니다(이 앱은 응답 모양이 맞지 않으면 버리므로 오류로 멈추지는 않음).
- Vercel 함수는 고정 IP가 없어 **막힐 가능성이 높습니다.** 도메인을 등록해도 Referer가 없어 거절된 사례가 있어, 요청에 Referer(배포 주소)를 싣도록 해 두었습니다.
- 대안(추천 순):
  1. **원문 미리 받아 넣기(무료, 추천)**: 칸 컴퓨터(IP 등록)에서 스크립트로 자배법·시행령 별표·상법 조문을 받아 `lib/law/data.json`으로 앱에 넣습니다. 약관 원문과 같은 방식이고 서버 호출이 없습니다. 법이 바뀌면 다시 받습니다.
  2. Vercel 고정 IP(Static IPs) 기능: 유료 추가 기능이라 쓰려면 칸의 승인이 필요합니다.
  3. 고정 IP가 있는 작은 중계 서버를 따로 둠: 서버 비용과 관리가 생깁니다.
- 지금처럼 LAW_API_OC가 없으면 "법령 원문 연결 전" 표시는 그대로입니다(배포 주소에서 확인).
- 출처: [OPEN API 오류자가진단](https://open.law.go.kr/LSO/support/noticeView.do?seq=7), [IP 접속이력 공지](https://open.law.go.kr/LSO/support/noticeView.do?seq=6), [이용안내](https://open.law.go.kr/LSO/information/service.do), [Referer 사례](https://github.com/domminc/calc/issues/25), [검증 실패 응답 사례](https://github.com/hadeshell1818-coder/ansimon-test/pull/7).
