# 기칸의 자동차보험 보상 나침반

이 프로젝트는 한국 자동차보험 보상 분석을 위한 Streamlit 1단계 실행본입니다.

## 포함 기능

- 사용자 입장 선택: 피해자 / 사고 운전자 또는 피보험자 / 쌍방과실 당사자 / 판단 어려움
- 사고내용 입력
- 보험증권 PDF 및 사진 업로드
- 담보 체크
- 과실률 선택
- 입력 내용 확인 화면
- 개인정보 마스킹
- 근거 부족 시 “추가정보 필요” 표시
- 약관·보험증권 근거 상태 안내

## 설치

```bash
python3 -m pip install -r requirements.txt
```

## 실행

```bash
streamlit run app.py
```

## 참고

- APP_SPEC.md를 기준으로 구성했습니다.
- 약관 PDF 4개는 파일명과 페이지 수만 확인했습니다.
- 합의금, 근거 없는 보험금, AI 임의 과실률은 계산하지 않습니다.
