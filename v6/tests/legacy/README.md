# 이식 로직 테스트 대조표

원본 compass 테스트는 V2 전체 엔진(`calculatePersonCoverages`·`calculateAccident`)을 거쳐 실행된다. v6는 그 엔진을 이식하지 않으므로, 같은 사례의 손 검산 숫자를 이식 함수에 직접 넣어 시험한다(결정 기록 D-1, 라운드 0 Q6 (가)).
- 원본 테스트는 V2 손해 산정(`buildLedger`)으로 손해 장부를 만든다. v6 테스트는 원본 주석에 적힌 손해액(치료관계비와 그 밖의 손해)으로 장부를 직접 만든다.
- 원본 기준: compass 커밋 `e58ffd1`.
- 규칙값은 두 곳에서 가져온다.
  - `lib/engine/legacy/data/fault.json`: 원본과 바이트 단위로 같다.
  - `tests/legacy/fixtures/bodily-limits.json`: 원본 `bodily-limits.json`에서 항목 6개만 그대로 뽑았다.
