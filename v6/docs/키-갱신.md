# 서류 인식 키 바꾸기 (처음 하는 분용)

앱의 "증권 읽기·서류 읽기·약관 묻기"는 Anthropic API 키로 동작합니다.
키가 만료되면 이 기능들만 "준비 중"으로 바뀌고, 직접 입력과 계산은 그대로 됩니다.
만료 7일 전부터 결과 화면 맨 아래에 작은 글씨로 **"문서 읽기·약관 질의 기능 점검 예정"** 이 보입니다.

키 값은 이 문서·코드·채팅 어디에도 적지 마세요. Vercel 화면과 내 컴퓨터의 `v6/.env.local` 파일에만 넣습니다.

---

## 1단계. 새 키 만들기

1. https://console.anthropic.com 에 로그인합니다.
2. 왼쪽 메뉴에서 **API Keys** 를 누릅니다.
3. 오른쪽 위 **Create Key** 를 누르고, 이름을 `kikhan-v6` 처럼 적은 뒤 **Create** 를 누릅니다.
4. 화면에 나온 키(`sk-ant-`로 시작)를 **Copy** 로 복사해 둡니다. 이 창을 닫으면 다시 볼 수 없습니다.
5. 키의 만료일을 확인해 적어 둡니다(예: `2027-05-21`). 만료일이 없으면 2단계의 AI_KEY_EXPIRES는 지워도 됩니다.

## 2단계. Vercel에 새 키 넣기 (화면으로)

1. https://vercel.com 에 로그인합니다.
2. 프로젝트 목록에서 **kikhan-auto-compass-v6** 를 누릅니다. (다른 프로젝트, 예: v4는 누르지 마세요.)
3. 위쪽 탭에서 **Settings** 를 누릅니다.
4. 왼쪽 메뉴에서 **Environment Variables** 를 누릅니다.
5. 목록에서 **ANTHROPIC_API_KEY** 줄 오른쪽의 **⋯(점 세 개)** → **Edit** 를 누릅니다.
6. **Value** 칸의 값을 지우고 새 키를 붙여 넣은 뒤 **Save** 를 누릅니다.
7. 같은 방법으로 **AI_KEY_EXPIRES** 줄의 **⋯ → Edit** 에서 값을 새 만료일(`YYYY-MM-DD`, 예: `2027-05-21`)로 바꾸고 **Save** 를 누릅니다.
8. 환경변수는 **다시 배포해야** 적용됩니다. 터미널에서 아래 두 줄을 붙여 넣습니다.

```bash
cd "/Volumes/KHAN_T7/앱개발(기칸 1)/kikhan-auto-insurance-V6/v6"
npm run deploy
```

9. 1~2분 뒤 https://kikhan-auto-compass-v6.vercel.app 에서 증권을 올려 읽히는지 확인합니다.

## 2단계 대신 터미널로 하기

터미널에서 아래를 차례로 그대로 복사해 붙여 넣으세요. 키를 묻는 줄이 나오면 새 키를 붙여 넣고 Enter를 누릅니다.

```bash
cd "/Volumes/KHAN_T7/앱개발(기칸 1)/kikhan-auto-insurance-V6/v6"
```

```bash
npx vercel@latest env rm ANTHROPIC_API_KEY production --yes --scope byunggis-6992
npx vercel@latest env add ANTHROPIC_API_KEY production --scope byunggis-6992
```

만료일을 바꿉니다. 아래 `2027-05-21`을 새 만료일로 고친 뒤 붙여 넣으세요.

```bash
npx vercel@latest env rm AI_KEY_EXPIRES production --yes --scope byunggis-6992
printf "2027-05-21" | npx vercel@latest env add AI_KEY_EXPIRES production --scope byunggis-6992
```

다시 배포합니다.

```bash
npm run deploy
```

배포는 늘 `npm run deploy` 하나로 합니다. 테스트 → 타입 검사 → 린트 → 빌드를 차례로 돌리고, 하나라도 실패하면 배포를 시작하지 않고 멈춥니다(마지막에 `ERR!`·`failed`가 보이면 배포되지 않은 것입니다).

## 3단계. 내 컴퓨터(시험용)에도 넣기

1. Finder에서 `kikhan-auto-insurance-V6/v6` 폴더를 엽니다. `.env.local`이 안 보이면 **Command + Shift + .(마침표)** 를 눌러 숨긴 파일을 보이게 합니다.
2. `.env.local`을 텍스트 편집기로 엽니다.
3. `ANTHROPIC_API_KEY=` 뒤의 값을 새 키로, `AI_KEY_EXPIRES=` 뒤의 값을 새 만료일로 바꾸고 저장합니다.
