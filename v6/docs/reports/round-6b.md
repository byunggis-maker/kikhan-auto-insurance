[1] **일용근로자 임금을 약관 공식으로 교체**(lib/claim/standards.ts, MASTER D-35)
- 공식은 (공사부문 보통인부 일급 + 제조부문 단순노무종사원 일급) ÷ 2입니다. 원 미만은 버리고, 월 임금은 × 25일입니다(별표1 인쇄 74쪽).
- 단가는 적용 시작일별 표 두 개로 나눴습니다. `dailyWageFor(사고일)`이 표마다 사고일에 적용 중인 단가를 하나씩 골라 평균을 냅니다. 한쪽이라도 없으면 '입력 필요'입니다.

  | 표 | 적용 시작일 | 일급 | 출처 |

  | `CONSTRUCTION_WAGES` 보통인부 | 2025-09-01 | 171,037 | 대한건설협회 |
  | | 2026-01-01 | 172,068 | 대한건설협회 |
  | | 2026-09-01 | 172,698 | 대한건설협회 |
  | `MANUFACTURING_WAGES` 단순노무종사원 | 2026-07-01 | 95,767 | 중소기업중앙회 |

  - 95,767원은 2026년 상반기 중소제조업 직종별 임금조사 값입니다.
  - 적용 시작일 2026-07-01은 2차 자료(언론 보도·노임단가 정리 글)에 따른 것입니다.
- 근거 칸(검토서·엑셀·PDF): 휴업손해 계산식과 "계산 기준"에 "(보통인부 172,698원 + 단순노무 95,767원) ÷ 2 = 134,232원, 약관 별표1(인쇄 74쪽)"과 월 25일 기준 금액이 나옵니다.
- "검토 필요" 표시는 계산식·계산 기준·안내에서 모두 지웠습니다. 단순노무 단가 원문 확인은 아래 질문 1로 남깁니다.
- 지난 라운드 질문 1 결과: 칸 지시대로 (가) 두 임금의 평균으로 바꿨습니다.
