# 법령 원문 받기·갱신 (처음 하는 분용)

앱은 법령 API를 직접 부르지 않습니다. 칸 맥(open.law.go.kr에 IP를 등록한 컴퓨터)에서 원문을 미리 받아 저장소에 넣고, 앱은 그 파일(`v6/data/laws/`)만 읽습니다.

- 원문이 있으면 결과 화면 '근거 법령'과 약관 질의 답변에 원문과 **"원문 기준일: YYYY-MM-DD (시행일 YYYY-MM-DD)"** 가 보입니다.
- 원문이 없거나 받은 지 **180일**이 넘으면 **"원문 갱신 필요"** 배지가 보입니다. 계산은 그대로 됩니다.
- 받는 조문은 앱 코드에서 인용 중인 조문과 기본 조문(자동차손해배상 보장법·시행령 별표, 민법 제396·760·763조, 상법 보험편)을 스크립트가 자동으로 모읍니다.

명령은 맥의 **터미널** 앱(Launchpad → 기타 → 터미널)에 그대로 복사해 붙여 넣고 Enter를 누르세요.

---

## 1. 처음 한 번: open.law.go.kr 준비

1. https://open.law.go.kr 에 회원가입하고 로그인합니다.
2. 위 메뉴의 **OPEN API** → **OPEN API 신청**에서 **법령(현행법령) 본문·목록** API를 신청합니다.
3. 신청 화면의 시스템 정보에 아래 두 가지를 적습니다.
   - 도메인주소: `https://kikhan-auto-compass-v6.vercel.app`
   - 서버 IP: **지금 이 맥의 IP**(아래 명령으로 확인)

```bash
curl -s https://api.ipify.org; echo
```

4. 승인되면 **마이페이지 → API인증키관리**에서 **OC 값**을 확인합니다.

## 2. 처음 한 번: OC 값을 내 맥에만 넣기

아래에서 `여기에OC값` 을 실제 OC 값으로 바꾼 뒤 붙여 넣으세요. 이 파일(`.env.local`)은 GitHub에 올라가지 않습니다.

```bash
cd "/Volumes/KHAN_T7/앱개발(기칸 1)/kikhan-auto-insurance-V6/v6"
echo 'LAW_OC=여기에OC값' >> .env.local
```

## 3. 원문 받기 (처음, 그리고 6개월에 한 번 또는 법이 바뀌었을 때)

```bash
cd "/Volumes/KHAN_T7/앱개발(기칸 1)/kikhan-auto-insurance-V6/v6"
npm run laws:fetch
```

- 끝에 `받은 조문 ○개` 가 나오면 성공입니다.
- `멈춤 — 인증 실패…` 또는 `IP 미등록…` 이 나오면 파일은 하나도 바뀌지 않습니다. 아래 **5. IP가 바뀌었을 때**를 하세요.
- `못 받음(예전 파일 유지)` 줄은 그 조문만 예전 파일을 그대로 둔다는 뜻입니다(별표가 그림으로만 제공되는 경우 등).

## 4. 저장소에 올리고 앱에 반영하기

맥의 저장소 폴더에는 아직 올리지 않은 Streamlit 작업(app.py 등)이 있어서, 그 파일을 건드리지 않도록 **잠깐 쓰는 별도 폴더**에서 `data/laws`만 올립니다. 아래를 한 번에 붙여 넣으세요.

```bash
cd "/Volumes/KHAN_T7/앱개발(기칸 1)/kikhan-auto-insurance-V6"
git fetch origin
git worktree add -f v6/.tmp/laws-push origin/main
cp v6/data/laws/*.json v6/.tmp/laws-push/v6/data/laws/
git -C v6/.tmp/laws-push add v6/data/laws
git -C v6/.tmp/laws-push commit -m "v6 법령 원문 갱신(npm run laws:fetch)"
git -C v6/.tmp/laws-push push origin HEAD:main
git worktree remove v6/.tmp/laws-push
```

- `nothing to commit` 이 나오면 바뀐 원문이 없다는 뜻입니다. 마지막 줄(`git worktree remove …`)만 실행하세요.
- force push는 쓰지 않습니다. `rejected`가 나오면 위 블록을 처음부터 다시 붙여 넣으세요.

이어서 배포합니다(앱에 원문이 들어갑니다).

```bash
cd "/Volumes/KHAN_T7/앱개발(기칸 1)/kikhan-auto-insurance-V6/v6"
npx vercel@latest --prod --yes --scope byunggis-6992
```

1~2분 뒤 https://kikhan-auto-compass-v6.vercel.app 결과 화면의 **근거 법령**에서 "원문 기준일"이 오늘 날짜인지 확인합니다.

## 5. IP가 바뀌었을 때 (집·카페 등 다른 인터넷, 공유기 교체)

`npm run laws:fetch`가 `인증 실패` 또는 `IP 미등록`으로 멈추면 대개 맥의 IP가 바뀐 것입니다.

1. 지금 IP를 확인합니다.

```bash
curl -s https://api.ipify.org; echo
```

2. https://open.law.go.kr 로그인 → **마이페이지** → **API인증값변경**(API인증키관리)에서 등록된 **서버 IP**를 위 값으로 고치고 저장합니다. (OC 값은 그대로입니다.)
3. 반영되는 데 시간이 걸릴 수 있습니다. 몇 분 뒤 **3번**을 다시 실행합니다.
4. 그래도 멈추면 OC 값이 `.env.local`의 `LAW_OC=` 와 같은지 확인하세요. 법제처 Open API 문의: 02-2109-6457.
