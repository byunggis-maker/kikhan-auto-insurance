## 점검하며 고친 것

- 보험 종류·역할 고르기 버튼이 좁은 칸에서 한 글자씩 줄바꿈되던 것 → 2열 격자로.
- 담보 카드의 최소·예상·최대 3칸에서 금액이 중간에 끊기던 것 → 예상을 크게 한 줄, 최소·최대를 아래 두 칸으로.
- 가린 값만 남은 괄호("자기차량손해 (피보험자 ******)") 때문에 기본 담보와 이름이 맞지 않던 것 → 판독 결과에서 그런 괄호를 지움.

## 못 고친 것·남은 문제

- 사진(JPG·HEIC)과 스캔 PDF는 그림 그대로 비전 LLM에 간다. 서버는 그림 속 글자를 미리 가릴 수 없어서 ① 사용자가 칠해 가리기 ② 판독 지시 ③ 결과 가리기에 기댄다.
- 크롬·안드로이드에서는 HEIC 사진을 화면에 그릴 수 없어 칠해 가릴 수 없다(아이폰 사파리는 된다). 캡처해 JPG로 올리라고 안내한다.
- 실제 제공자(OpenAI·Anthropic)의 판독 품질은 키가 없어 확인하지 못했다(가짜 제공자로 흐름만 확인).
- 이름처럼 항목 이름 없이 문장에 섞인 개인정보는 정규식으로 다 잡지 못한다(`redact.ts` 머리말).
